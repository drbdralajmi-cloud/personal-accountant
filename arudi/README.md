# منصّة العَروض

منصّة عربية لتعلّم علم العروض وتحليل أوزان الشعر. تقرأ البيت **كما يُنطق لا كما يُرسم**، فتسمّي
بحره، وتعرض تقطيعه وتفعيلاته، وتدلّ على موضع الكسر إن وُجد، وتشرح سبب كل نتيجة.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # اختبارات المحرّك والمحتوى
```

لا تحتاج قاعدة بيانات ولا حساباً لتشغيلها.

## المحرّك العروضي

قلب المشروع في `src/lib/arud/`، وليس فيه أيّ اعتماد على خدمة خارجية.

| الملف | وظيفته |
| --- | --- |
| `prosodic.ts` | الكتابة العروضية: فكّ الشدّة، التنوين، همزة الوصل، إدغام لام التعريف، الحروف غير المنطوقة، حذف المدّ لالتقاء الساكنين، إشباع آخر الشطر |
| `feet.ts` | التفعيلات الثماني بزحافاتها وعللها، ممثَّلةً بسلاسل ثنائية (١ متحرك، ٠ ساكن) |
| `meters.ts` | ٢٦ صورة وزنية للبحور الستة عشر (تام/مجزوء/مشطور/مخلّع) والخبب |
| `matcher.ts` | المطابقة التامّة بالتراجع، والمطابقة التقريبية بمسافة التحرير |
| `analyze.ts` | تقسيم البيت وترجيح البحور وتوليد الشرح |
| `rhyme.ts` | الرويّ ونوع القافية وحركتها ولواحقها |
| `compose.ts` | تأليف أشطر موزونة، واقتراح بدائل للكلمة المكسورة، والقوافي |

### كيف يُحلَّل بيتٌ غير مشكول؟

التشكيل الناقص هو أصعب ما في التحليل الآلي. بدل تخمين الحركات أولاً ثم القياس عليها، **يُستعمل
الوزن نفسه قيداً يحسم الحركات المجهولة**: يمشي البحث في العمق على حروف البيت وعلى خانات البحر
معاً، فكلّما بلغ حرفاً مجهول الحركة أخذ منه ما تقتضيه التفعيلة، وكلّما تعذّر الاستمرار تراجع.
فيخرج التشكيل والوزن معاً في مسارٍ واحد، ويكون كل تشكيلٍ ناتج موافقاً لبحرٍ صحيح بالضرورة.

القواعد الصوتية التي لا تحتاج إلى وزن (الألف ساكنة أبداً، وأول الكلمة متحرك أبداً، وحرف المدّ
ساكنٌ بعد حركته المجانسة) تُحسم قبل البحث فتقلّل المجهولات وتسرّع المطابقة.

### كشف الكسر

إذا لم يطابق البيت أيّ بحر مطابقةً تامّة، يُشغَّل بحث «صفر–واحد» في العمق الأول على مخطّط
حالات (موضع الحرف، رقم الخانة، الصورة، الموضع داخلها) بعمليات إبدال وحذف وإضافة، فتُعرف أقرب
البحور وموضعُ الخلل بالتحديد: أيّ تفعيلة، وكم حرفاً ينقصها أو يزيد فيها.

### التصريع

عروض البيت قد تُلحَق بضربه في المطالع، فتُضمّ صور الضرب إلى خانة العروض تلقائياً عند بناء البحور
بدل تعدادها يدوياً لكل بحر.

## المعجم الموزون

‏١٢٬٩٦٣ كلمة مشكولة مفهرسة بتقطيعها (`src/lib/lexicon.ts`)، من مصدرين:

- **معتمدة** (٥٢٦ كلمة): منتقاة مثبتة في المعاجم.
- **قياسية** (١٢٬٤٣٧ صيغة): مولَّدة من ٢٩٠ جذراً ثلاثياً صحيحاً سالماً على ٥٣ وزناً صرفياً.
  القالب الصرفي يحدّد التشكيل تحديداً تامّاً، فتقطيعُها قطعيٌّ لا ظنّي — وقد لا يكون بعضها
  مستعمَلاً في كلام العرب، ولذلك تُميَّز في الواجهة ويمكن استبعادها بمفتاح واحد.

كل كلمة مفهرسة بثلاث حالات — **وقف** (آخرها ساكن)، و**وصل** (آخرها متحرك داخل الشطر)،
و**تنوين** — وبهذا تصير كل تفعيلة قابلةً للملء، بما فيها `مَفْعُولَاتُ` التي ينتهي رمزها بمتحرك
فلا تطابقها كلمةٌ مفردة موقوفة.

## الأقسام

| المسار | المحتوى |
| --- | --- |
| `/` | تعريف بالعلم، بحث سريع، بطاقات البحور والقوالب، تدريب اليوم، آخر الدروس |
| `/analyze` | تحليل بيت أو شطر أو قصيدة كاملة، مع التلوين والشرح واقتراح التصحيح |
| `/taf3ilat` و `/taf3ilat/[slug]` | القوالب الثماني: الشرح والتقسيم الصوتي وعدد المقاطع والنطق، و٥٠ كلمة على الوزن مع توليد مجموعة جديدة |
| `/buhur` و `/buhur/[slug]` | البحور ودوائر الخليل، وبنية كل بيت بصوره الجائزة، وتأليف شطر على البحر |
| `/assistant` | محرّر يحلّل أثناء الكتابة ويقترح البدائل والقوافي والشطر المكمّل |
| `/training` | ستّة أنواع من التمارين بثلاثة مستويات، مع مخطّط تقدّم ومتتالية أيام |
| `/lessons` | عشرة دروس مرتّبة، مع اختبار بعد كل درس |
| `/search` | بحث بالتفعيلة أو نصّ الكلمة أو القافية أو عدد المقاطع |
| `/favorites` | المفضّلة وسجلّ البحث (محلّيان في المتصفّح) |
| `/admin` | إحصاءات المحتوى وتغطية المعجم وفحص سلامة آلي |

واجهات البرمجة: `/api/analyze`، `/api/words`، `/api/compose`، `/api/exercises`، `/api/health`.

## التقنيات

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Chart.js · Lucide ·
Prisma + PostgreSQL (اختياري) · NextAuth (اختياري) · PWA للعمل دون اتصال.

دعم كامل للعربية واتجاه RTL، ووضعان فاتح وداكن، وتصدير PDF عبر الطباعة، ومشاركة النتائج، ونطق
الكلمات عبر محرّك النطق المدمج في المتصفّح.

## قاعدة البيانات والحسابات — اختيارية

الموقع يعمل كاملاً بدونهما. لتفعيلهما انسخ `.env.example` إلى `.env` واضبط ما تريد، ثم:

```bash
npm run db:push     # إنشاء الجداول
npm run db:seed     # بذر البحور والتفعيلات والمعجم والدروس
```

جهات الدخول (جوجل، آبل، البريد) تُفعَّل كلٌّ منها عند توفّر مفاتيحها وحدها.

## حدود معروفة

- **التشكيل الناقص قد يحتمل أكثر من بحر.** «ألا لا يجهلن أحد علينا» غير مشكولة تصحّ على المتقارب
  كما تصحّ على الوافر. تُعرض البحور المرشّحة كلّها بدرجات ثقتها، ويحسم التشكيلُ الأمرَ.
- **الأشطر المؤلَّفة آلياً موزونةٌ لا موحية.** تُبنى بتبليط وزن الشطر بكلمات المعجم، فتصحّ وزناً
  ولا تدّعي معنًى شعرياً — وهي مُعلَّمة بذلك في كل موضع تظهر فيه.
- **الصيغ القياسية ليست كلّها مستعملة.** مولَّدة من جذورٍ وأوزانٍ حقيقية وتقطيعها صحيح، لكنّ بعضها
  غير مسموع؛ ولذلك تُميَّز عن المعتمدة ويمكن استبعادها.
- **النطق يعتمد على المتصفّح.** يستعمل `SpeechSynthesis`، وجودته تختلف باختلاف الأصوات العربية
  المتاحة على الجهاز.
